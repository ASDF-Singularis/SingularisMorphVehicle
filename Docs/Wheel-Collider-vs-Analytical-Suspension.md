# 车轮碰撞体与解析悬挂的双重支撑冲突

> [!IMPORTANT]
> 在 **单刚体（Single Rigid Body）** + **解析悬挂（Analytical Suspension）** 模型中，车轮视觉件的 **碰撞体（Collider）** 一旦与地面发生 **刚体接触（Rigid Body Contact）**，就与解析悬挂构成 **双重支撑（Dual Support）**：整车的接地由悬挂切换为刚性接触，表现为「被顶起后变硬」，这是该模型的标志性失效模式。

## 1. 模型前提

**单刚体（Single Rigid Body）** + **解析悬挂（Analytical Suspension）** 模型的成立前提：

1. 整辆载具对应**唯一**的物理刚体；
2. 悬挂与车轮是刚体内部的**解析子系统**，不是独立物理体；
3. 接地由**射线（Raycast）测量 + 解析求解**表达，而非由几何接触的 **约束求解（Constraint Solving）** 产生；
4. 悬挂产出的是 **解析力（Analytical Force）** 或解析约束，统一施加到唯一刚体上。

由此得到一个核心特征：**几何表现与实际接触解耦**。车轮显示在画面上，但车轮本身不参与物理接触求解。

## 2. 两套支撑来源

一旦参与渲染的部件同时带有可阻挡的碰撞体，接地就可能由两套互不知情的机制同时提供：

| 维度 | 解析悬挂支撑 | 刚体接触支撑 |
|---|---|---|
| 几何来源 | 射线测量 + 解析公式 | 碰撞体与地面的约束求解 |
| 作用对象 | 唯一刚体 | 碰撞体所属的刚体 |
| 高度由谁决定 | 悬挂长度 + **车轮半径（Wheel Radius）** | 碰撞体几何与地面约束 |
| 刚度 | 弹簧/阻尼（可调、连续） | 刚性（近似无穷大） |
| 是否检测穿透 | 不适用 | 是 |

## 3. 冲突判据

记：

- `R` = **车轮半径（Wheel Radius）**，即悬挂解算使用的半径；
- `R_c` = 碰撞体的实际几何半径。

悬挂决定 **轮心离地高度（Wheel Center Height）** 等于 `R`。碰撞体接地要求轮心离地高度等于 `R_c`。二者之差构成冲突判据：

```
Δ = R − R_c
```

| 状态 | 条件 | 轮心离地 | 碰撞体相对地面 | 接地由谁提供 | 结果 |
|---|---|---|---|---|---|
| 悬挂支撑 | `Δ > 0` | `R` | 悬空 `Δ` | 解析悬挂 | 正常、可调、软 |
| 双重支撑临界 | `Δ = 0` | `R = R_c` | 恰好接地 | **刚体接触**（悬挂仍施力） | 被顶起后变硬 |
| 穿透 | `Δ < 0` | `R` | 嵌入 `\|Δ\|` | 约束反复修正 | 穿透/弹跳/抖动 |

`Δ` 的符号决定系统处于哪种支撑模式；`Δ` 穿过 0 时，支撑模式发生切换，行为不连续。

## 4. 失效机理

刚体接触接管接地后，载具失效的来源是**同一份「车体到地面的距离」被两套机制同时约束**：一套柔软可调（解析悬挂），一套刚性（刚体接触）。硬的那套接管后，悬挂的功能被夺走。具体分为三点。

### 4.1 刚度失配（Stiffness Mismatch）

解析悬挂的刚度有限且可调；刚体接触刚度近似无穷大。两者同时作用于**同一个刚体**时，位移响应由高刚度者主导，悬挂失去调节离地高度的能力。悬挂仍按其内部模型计算位移与力，但这些量不再对应实际姿态。

### 4.2 压缩行程被硬性封锁（Travel Blocking）

悬挂的功能是让「车体到地面的距离」随载荷**软性变化**，即通过轮心相对车体的上移（压缩）与下移（伸张）吸收载荷与地形起伏。刚体接触不允许碰撞体穿透地面，等价于对「车体到地面的距离」施加了一个**硬下限**：

- 车体**可以上抬**（碰撞体离地）；
- 车体**不能下沉**（否则碰撞体穿透）。

结果是压缩方向无行程，只能上抬、不能下沉 → 表现为「硬」，失去缓冲能力。

### 4.3 过约束与载荷失真（Over-constraint）

悬挂持续朝自身目标施力，刚体接触则把车体钉在地面高度，两者相互对抗，产生与真实静载无关的内力。而轮胎的载荷、抓地力与纵向力是**按悬挂力推导**的：

- 计算载荷来自悬挂；
- 实际支撑来自刚性接触；
- 二者不一致 → 抓地力、制动/驱动力的幅值失真 → 推不动 / 锁死。

### 4.4 与「射线读到悬空」的关系（澄清）

失效**并非**因为悬挂射线读到悬空：

- 射线检测的是**地面**，并按其碰撞通道忽略车轮自身；车轮碰撞体接地**不改变射线的命中结果**。在 `ℓ ≤ D` 时，射线仍然命中地面，悬挂仍判断为触地。
- 失效发生时真正改变的是：**决定离地高度与刚度的机制由「射线 + 解析悬挂」替换为「刚体接触」**，而不是射线的读数。
- 只有当刚体接触把车体抬到安装点高度超过 `D + R` 时，射线终点高于地面而**失地（Airborne）**；此时悬挂连测量都失去，退回行程端点。这属于**次级后果**，不是起因。

## 5. 为什么半径变化会引起突变

关键事实：

- **碰撞体几何是固定的**，由模型网格决定，不随参数 `R` 变化；
- **参数 `R` 只进入解析悬挂的解算**，改变的是「悬挂把轮心顶到多高」。

因此 `R` 是一个自由参数，而 `R_c` 是一个几何常数。`Δ = R − R_c` 随 `R` 线性变化：

- `R` 大于 `R_c`：碰撞体悬空，悬挂承担全部支撑（表面"正常"，但车轮实际离地 `Δ`，是隐藏的几何错位）；
- `R` 收敛到 `R_c`：碰撞体落地，接触支撑接管（刚性）；
- `R` 小于 `R_c`：碰撞体嵌入地面（穿透）。

**表现上的"正常工作"可能只是碰撞体悬空带来的假象；把参数调到与几何一致，反而触发刚体接触。**

## 6. 标志性与普适性

该失效模式并非某个参数组合的偶然，而是「表现与接触解耦」模型的固有属性：

- 只要存在一个**参与渲染却带有实体碰撞**的部件，它就构成悬挂之外的第二个支撑源；
- 该部件可以是车轮，也可以是任何 **焊接（Weld）** 进主体、或作为 **附着（Attachment）** 传入的实体；
- 参数（半径）的调整不改变碰撞几何，却改变悬挂的落点，从而使二者的相对关系跨越临界值。

理解它，等价于理解该模型的边界：**承载接地职责的只能是解析悬挂（或明确的独立物理轮方案），不能是渲染件的碰撞体。**

## 7. 现象清单（诊断信号）

| 现象 | 指向 |
|---|---|
| 车体被顶起**之后**才变硬 | 悬挂先把车顶到碰撞体触地的高度，之后由刚体接触接管 |
| 整车"硬"，无行程吸收 | 刚性接触刚度远高于悬挂；压缩行程被封锁 |
| 推不动 / 打滑锁死 | 刚体接触与轮胎解析力的载荷失真 |
| 改变半径后行为**突变** | `Δ` 跨越 0 |
| 仅当"接地"时异常，悬空时正常 | 异常只在碰撞体接触地面的时刻出现 |
| 车轮视觉上悬在离地 `Δ` 处却"正常" | `Δ > 0`，碰撞体未接地 |
| 射线仍报触地但车体不动 | 失效来自支撑机制切换，而非射线失地 |

## 8. 正确配置原则

1. **承载接地职责者**：解析悬挂 + 主体的碰撞体。
2. **车轮视觉件**：不得带有**可阻挡**的碰撞体（设为无碰撞，或至少不阻挡地面）。
3. **不得用渲染件的碰撞体承担支撑**：任何焊接/附着进来的实体车轮，其碰撞体都会成为第二支撑源。
4. **若必须使用物理轮接触**（碾过障碍、真实轮胎形变等）：则不再是本模型，须改用「独立物理轮刚体 + 约束」方案，与本解析悬挂互斥，不能共存。
5. **半径一致性**：若保留任何接触几何，`R` 必须与 `R_c` 一致，且明确二者的相对关系恒为正（碰撞体始终悬空）。

## 9. 直观图示

### 9.1 判据与三种状态

```
Δ = R − R_c

   Δ > 0  （悬挂支撑）        Δ = 0  （双重支撑：硬）        Δ < 0  （穿透）
        ● 轮心                    ● 轮心                     ● 轮心
        │ R                       │ R = R_c                  │ R
        │                         │                          │
        ○ 碰撞体底                 ○ 碰撞体底                  ▓ 碰撞体
        │ 悬空 Δ                   │ 接地                      ▓ 嵌入地面
   ═════╧════ 地面           ═════╧════ 地面             ═════╧════ 地面
```

### 9.2 支撑职责的切换

```
     正常（悬挂支撑）                     变硬（刚体接触支撑）
   ┌───────────────┐                  ┌───────────────┐
   │     主体       │                  │     主体       │
   └───────┬───────┘                  └───────┬───────┘
       解析悬挂                             解析悬挂（仍在施力，但已被架空）
           │                                    │
        ● 轮心  ← 离地 R                     ● 轮心  ← 离地 R
        ○ 碰撞体（悬空）                      ○ 碰撞体（接地，接管支撑）
   ═════════════════ 地面              ═════════════════ 地面
                                        ↑ 支撑由悬挂切换为刚性接触
```

### 9.3 压缩行程被封锁

```
   正常：车体可下沉（悬挂压缩）            变硬：碰撞体不允许车体下沉
   ┌───────────────┐                    ┌───────────────┐
   │     主体  ↓    │  ← 吸收载荷         │     主体  ✗    │  ← 无法下沉
   └───────┬───────┘                    └───────┬───────┘
       解析悬挂（压缩）                        解析悬挂（压缩被刚性接触阻断）
        ● 轮心（相对上移）                      ● 轮心（相对位移被锁死）
        ○ 碰撞体（悬空，不参与）                ○ 碰撞体（接地，成为硬下限）
   ═════════════════ 地面                ═════════════════ 地面
```

### 9.4 参数扫描下的不连续

```
   行为
    ▲
    │  正常（碰撞体悬空）
    │──────────────────
    │                    ╲
    │                     ╲  突变
    │                      ╲
    │                       ●──── 硬（碰撞体接地）
    │                            ╲
    │                             ╲ 穿透/弹跳
    └──────────────┬──────┬───────▶  R
                  R>R_c  R=R_c   R<R_c
```

## 10. 检查清单

1. 是否有任何参与渲染的部件带有**可阻挡**碰撞体（车轮或其他附件）？
2. 参数 `R` 与碰撞体几何半径 `R_c` 的差 `Δ` 是否恒为正（碰撞体始终悬空）？
3. 参数 `R` 改小是否使行为突变（`Δ` 跨越 0）？
4. 接地职责是否**唯一**由解析悬挂与主体碰撞体承担？
5. 是否存在被 **焊接（Weld）** 或 **附着（Attachment）** 引入的实体车轮，其碰撞体在接地承重？
6. 视觉件与其碰撞几何是否一致的对齐（`Δ` 是否被误当作"悬架高度"）？
7. 当车体变硬时，悬挂射线是否**仍报触地**？若仍报触地，则失效来自**支撑机制切换**（第 4 节），而非射线失地。
