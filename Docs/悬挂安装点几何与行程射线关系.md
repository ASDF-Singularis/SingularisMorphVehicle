# 安装点几何、车轮半径、行程限位与射线的几何关系

> [!IMPORTANT]
> **安装点（Mount）** 给出射线的固定原点与轮心的标称位置，**最大上抬（Max Raise）** 与 **最大下压（Max Drop）** 固定轮心沿 **悬挂轴（Suspension Axis）** 的一维行程区间，**车轮半径（Wheel Radius）** 同时决定 **射线（Raycast）** 的终止位置与轮心到地面的基准距离，四者共同决定射线能否触地以及 **悬挂长度（Suspension Length）** 的解算结果。

## 1. 符号与约定

| 符号 | 名称（英文） | 含义 | 单位 |
|---|---|---|---|
| **M** | **安装点（Mount）** | 悬挂在底盘上的固定安装参考点，即轮心的标称位置 | 位置 |
| **a** | **悬挂轴（Suspension Axis）** | 单位向量，方向由底盘指向地面，即轮心的一维运动方向 | 无量纲 |
| **R** | **车轮半径（Wheel Radius）** | 轮胎的几何半径 | 长度 |
| **U** | **最大上抬（Max Raise）** | 轮心相对安装点沿 −a（向上）的最大位移 | 长度 |
| **D** | **最大下压（Max Drop）** | 轮心相对安装点沿 +a（向下）的最大位移 | 长度 |
| **T** | **总行程（Total Travel）** | `T = U + D` | 长度 |
| **ℓ** | **悬挂长度（Suspension Length）** | 轮心相对安装点沿 a 的带符号偏移，`ℓ ∈ [−U, +D]` | 长度 |
| **c** | **压缩量（Compression）** | 相对满伸张的向上位移，`c = D − ℓ`，`c ∈ [0, T]` | 长度 |
| **h** | **离地高度（Ride Height）** | 安装点沿 a 到地面的距离 | 长度 |
| **s** | **命中距离（Hit Distance）** | 射线起点沿 a 到地面的距离 | 长度 |

约定：沿 **a** 为正向（向下），逆 **a** 为负向（向上）。沿轴向的一切距离均为带符号标量。`ℓ = 0` 表示轮心与安装点重合；`ℓ > 0` 为下垂（**Droop**），`ℓ < 0` 为压缩（**Bump**）。

## 2. 几何量定义

### 2.1 安装点（Mount）

安装点是固定在底盘局部坐标系中的一点，是：

1. 悬挂一切轴向度量的零点（`ℓ` 的原点）；
2. 射线的定位基准；
3. 轮心的标称位置（`ℓ = 0`）。

安装点与轮心之间的关系等价于对 `ℓ` 的一个常数偏置：若安装点与车轮的几何原点不重合，该偏差将被并入 `ℓ`，并占用行程区间的余量。

### 2.2 悬挂轴（Suspension Axis）

轮心只能沿 **a** 运动，`ℓ` 是该方向上唯一的自由度。安装点必须位于过轮心的该轴上；若安装点偏离该轴（横向偏移），射线测得的距离不再对应车轮的真实接地位置。

### 2.3 车轮半径（Wheel Radius）

半径 `R` 表达一个几何事实：车轮触地时，轮心恒位于地面之上 `R` 处（沿 −a）。

### 2.4 最大上抬（Max Raise）与最大下压（Max Drop）

行程区间为 `ℓ ∈ [−U, +D]`：

- `ℓ = −U`：满压缩（轮心最高）；
- `ℓ = +D`：满伸张（轮心最低）；
- 区间宽度 `T = U + D` 即总行程。

### 2.5 悬挂长度（Suspension Length）与压缩量（Compression）

悬挂长度 `ℓ` 是状态量；压缩量 `c = D − ℓ`，在满伸张处为 0，在满压缩处为 `T`。悬挂产出的轴向支撑力是 `c` 的单调函数（线性弹簧取 `F ∝ c`），阻尼项与 `dℓ/dt` 成正比。

## 3. 射线（Raycast）与解算

### 3.1 起点与终点

射线从安装点上方 `U` 处出发，到安装点下方 `D + R` 处结束：

```
P0 = M − a·U          （射线起点，轮心最高位置）
P1 = M + a·(D + R)    （射线终点，满伸张时车轮最底点）
射线长度 L = U + D + R = T + R
```

- 起点由 `U` 决定：保证起点位于轮心可达的最高位置之上；
- 终点由 `D + R` 决定：保证车轮在满伸张触地时，射线仍能覆盖到地面。

### 3.2 命中距离到悬挂长度的映射

设命中距离为 `s`（自 P0 沿 a 计）。安装点在地面之上 `h` 处，故：

```
s = U + h
h = s − U
```

再结合 `h = ℓ + R`（见 §4.1），得解算式：

```
ℓ = s − U − R
```

对应关系：

| 轮心状态 | `ℓ` | 命中距离 `s` |
|---|---|---|
| 满压缩 | `−U` | `R` |
| 标称位置 | `0` | `U + R` |
| 满伸张 | `+D` | `U + R + D = L` |

命中点愈靠近射线起点，`s` 愈小，`ℓ` 愈小，即压缩量 `c` 愈大。

### 3.3 触地判定与钳制

- **触地判定（Ground Contact）**：射线命中即视为车轮触地；未命中即视为悬空。
- **钳制（Clamping）**：解算出的 `ℓ` 被限制在 `[−U, +D]`。命中点超出区间（或未命中）时，`ℓ` 取区间端点，行程到达机械限位。
- 未命中时，`s` 无定义，`ℓ` 无法解算，系统退回到行程端点（通常为满伸张）：车轮悬垂、不提供支撑力。

## 4. 关系（核心）

### 4.1 离地高度关系

车轮触地时，安装点到地面的距离由两段构成：

```
h = ℓ + R
```

即**安装点高度 = 悬挂长度 + 车轮半径**。`R` 是直接叠加到离地高度上的常数项；`ℓ` 由载荷与弹簧刚度决定的平衡点给出。因此在平衡状态下，半径每增加 `ΔR`，安装点静止高度随之增加 `ΔR`。

### 4.2 射线可达条件

射线终点相对地面的下探余量为：

```
(D + R) − h = (D + R) − (ℓ + R) = D − ℓ
```

- `D − ℓ > 0`：终点在地面之下，射线可达；
- `D − ℓ = 0`：终点恰落在地面，临界；
- `D − ℓ < 0`：终点在地面之上，**射线失地**。

故可达条件为：

```
ℓ ≤ D
```

等价于 `h ≤ D + R`：安装点高度不能超过「最大下压 + 车轮半径」。

### 4.3 半径与工作点

半径同时进入两个环节：

1. **解算式** `ℓ = s − U − R`：半径误差 `ΔR` 直接造成等量的悬挂长度误差 `−ΔR`（进而造成等量的压缩量误差与支撑力误差）；
2. **可达条件** `h ≤ D + R`：半径增大抬高可达上限；半径减小压低可达上限（见 §6）。

### 4.4 限位与刚度

- 当 `ℓ` 落在区间内部时，支撑力随 `c = D − ℓ` 变化，悬挂具有吸收行程；
- 当 `ℓ` 触达 `−U` 或 `+D` 时，行程耗尽，支撑力不再随位移增长（硬限位），悬挂表现为刚体；
- 悬挂的静态工作点由「支撑力 = 载荷」确定，该点应位于区间内部并留有余量，使上抬与下压两个方向均有可用行程。

## 5. 直观图示

### 5.1 轴向一维布局

```
  a (向下) ↓

  P0 ●  ── 射线起点            = M − a·U
     │
     │  U                       最大上抬 (Max Raise)
     │
  M  ●  ── 安装点 (Mount)      = 轮心标称位置 (ℓ = 0)
     │
     │  D                       最大下压 (Max Drop)
     │
  P1 ●  ── 射线终点            = M + a·(D + R)
```

### 5.2 轮心行程区间

```
   ℓ = −U   ●  满压缩（轮心最高）
            │
   ℓ =  0   ●  标称（= 安装点）
            │
   ℓ = +D   ●  满伸张（轮心最低）
```

### 5.3 侧视：触地时的三段关系

```
                 ┌───────────────────┐
                 │      底盘           │
                 └─────────┬─────────┘
                           │
                           ●  安装点 M
                           │
                           │  ℓ        ← 悬挂长度 (Suspension Length)
                           │
                        ╭──┴──╮
                        │ 轮心 │
                        ╰──┬──╯
                           │  R        ← 车轮半径 (Wheel Radius)
        ═══════════════════╧═════════════  地面
                        h = ℓ + R
```

### 5.4 可达与失地

```
   可达：D − ℓ > 0                     失地：D − ℓ < 0
        ● 安装点                            ● 安装点
        │                                   │
        ● 射线终点                          ● 射线终点   ← 终点高于地面
   ═════╪════ 地面                     ═════╪════ 地面
                                            （射线未触及地面）
```

## 6. 参数错配的后果

| 错配 | 直接后果 |
|---|---|
| `R` 偏小（物理半径 < 实际半径） | `ℓ = s − U − R` 偏大 → 读出的悬挂长度偏长、压缩量偏小；同时可达上限 `D + R` 降低 → **射线失地风险升高**，失地时 `ℓ` 退回端点，行程消失 |
| `R` 偏大 | `ℓ` 偏小 → 读出的压缩量偏大；离地高度 `h = ℓ + R` 抬高 → **车身静止高度偏高** |
| `D` 偏小 | 可达条件 `ℓ ≤ D` 收紧 → 静止时更接近满伸张 → 下压余量不足或失地 |
| `U` 偏小 | 压缩余量 `ℓ ≥ −U` 收紧 → 静止时更接近满压缩 → 上抬余量不足 |
| 安装点偏离轴线 | 射线距离不再对应轮心接地 → 悬挂长度解算存在系统性偏差 |
| 安装点与轮心不重合 | 偏差并入 `ℓ`，直接消耗行程余量 |
| `U`、`D` 与几何不符 | 静止工作点贴近限位 → 悬挂「刚性」、无吸收 |

关键判据：**静止工作点 `ℓ_rest` 必须落在 `(−U, +D)` 内部并留有余量，同时满足 `ℓ_rest < D` 以保证射线可达。**

## 7. 自洽性检查清单

1. 安装点与车轮几何中心是否重合，且位于悬挂轴上。
2. 车轮半径 `R` 是否等于车轮的实际几何半径。
3. 静止时安装点离地高度 `h_rest` 是否满足 `h_rest = ℓ_rest + R`，且 `ℓ_rest` 位于行程区间内部。
4. 射线下探余量 `D − ℓ_rest` 是否显著大于零（保证可达且留有余量）。
5. 上抬余量 `ℓ_rest + U` 与下压余量 `D − ℓ_rest` 是否大致平衡（保证双向行程）。
6. 射线是否经过轮心（安装点无横向偏移）。
